# Motion-o Paper Materials

[![Project Page](https://img.shields.io/badge/GitHub_Pages-Visit_IO_Page-181717?style=flat&logo=github)](https://ostadabbas.github.io/motion-o.github.io/)

This folder contains the materials accompanying our paper submission.  
**Link to the IO page:** [https://ostadabbas.github.io/motion-o.github.io/](https://ostadabbas.github.io/motion-o.github.io/)

## Contents

* **Supplementary PDF**: `supplementary.pdf`
  Contains the supplementary material, including extended benchmark analysis, training details, and additional qualitative/quantitative discussion.

* **Code Archive**: `motion-o.zip`
  Contains the codebase associated with the paper.

* **Interactive HTML IO Page**: `index.html`
  Open this file in a browser to view the interactive demo / HTML interface.

## Directory Structure

```text
.
├── README.md
├── supplementary.pdf
├── motion-o.zip
└── index.html
```

## Reviewer Guide

To help navigate the submission materials:

1. Start with **`supplementary.pdf`** for the extended experimental details, benchmark analysis, training details, and additional results.
2. Open **`index.html`** in a web browser for the interactive HTML IO page.
3. See **`motion-o.zip`** for the source code and implementation files.
